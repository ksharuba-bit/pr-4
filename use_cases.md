# Варіанти використання

| Основний актор | Найменування | Формулювання |
|---|---|---|
| Адміністратор | Керування користувачами | Дозволяє створювати, редагувати та блокувати облікові записи користувачів системи. |
| Адміністратор | Керування правами доступу | Дозволяє призначати ролі та визначати доступ користувачів до функцій системи. |
| Організатор турніру | Створення турніру | Дозволяє створити новий футбольний турнір і задати його основні параметри. |
| Організатор турніру | Реєстрація команди | Дозволяє додати команду до вибраного турніру. |
| Організатор турніру | Формування календаря | Дозволяє створити або відредагувати розклад матчів між командами. |
| Організатор турніру | Внесення результату матчу | Дозволяє зберегти рахунок завершеного матчу та оновити статистику. |
| Організатор турніру | Формування турнірної таблиці | Дозволяє автоматично розрахувати очки, перемоги, нічиї, поразки та місця команд. |
| Аналітик | Перегляд статистики | Дозволяє переглядати статистичні показники команд і турніру. |
| Аналітик | Порівняння команд | Дозволяє порівнювати результати двох або кількох команд за вибраними показниками. |
| Аналітик | Сортування та фільтрація | Дозволяє впорядковувати і відбирати статистичні дані за заданими критеріями. |
| Аналітик | Формування звіту | Дозволяє сформувати підсумковий або аналітичний звіт за результатами турніру. |
| Представник команди | Перегляд даних команди | Дозволяє переглядати результати, календар і статистику своєї команди. |
| Глядач | Перегляд турнірної таблиці | Дозволяє переглядати актуальне розташування команд у турнірі. |
| Глядач | Перегляд результатів матчів | Дозволяє переглядати результати зіграних матчів. |
| Глядач | Перегляд розкладу | Дозволяє переглядати заплановані матчі турніру. |
