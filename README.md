# Лабораторна робота №4 — актори та варіанти використання

**Тема проєкту:** Розроблення інформаційної системи для статистичного аналізу футбольних турнірів із використанням технології об'єктно-орієнтованого програмування.

**Студент:** Шоробура Костянтин  
**Група:** ІК-52

## Мета роботи

Виявити основних акторів розроблюваної системи, класифікувати їх, сформувати реєстр акторів, визначити для кожного актора варіанти використання та побудувати діаграму прецедентів.

## Файли репозиторію

- `actors.md` — реєстр акторів та їх короткий опис;
- `use_cases.md` — перелік варіантів використання;
- `use_case_diagram.puml` — PlantUML-діаграма варіантів використання.

## Основні актори

1. Адміністратор.
2. Організатор турніру.
3. Аналітик.
4. Представник команди.
5. Глядач / користувач системи.

## Основні можливості системи

- реєстрація команд;
- створення та редагування турніру;
- внесення результатів матчів;
- автоматичне формування турнірної таблиці;
- перегляд статистики;
- пошук і фільтрація даних;
- формування підсумкових звітів;
- керування користувачами системи.
